# 中文文章寫作（避開 AI 句法地雷）

## 目的 Goal

幫使用者**寫**或**改**一篇讀起來像「真人寫的」中文文章。重點不是把詞句變華麗，而是把 AI 模型常見的八種句法習慣**主動拆掉**，讓每一句話都有新資訊、語氣自然、邏輯乾淨。

此 skill 的內容啟發自吳淡如老師在 YouTube 頻道 [吳淡如人生實用商學院](https://www.youtube.com/@betty_wu) 上的分享：[【吳淡如】EP5 — 為什麼你的 AI 文案這麼假？我用寫作超過 50 年的經驗告訴你 AI 寫文的 8 個地雷](https://www.youtube.com/watch?v=eIeqTmCM9Vo)。八大地雷與配套工作流都來自吳淡如老師本人超過 50 年的中文寫作經驗。請把這份 skill 當成**寫作風格守則 + 自我檢查清單**，不是單純的搜尋規則。

## 何時使用 When to Use

當使用者要求：

- 用中文寫一篇文章、貼文、文案、心得、報告、書稿、廣告詞、newsletter。
- 把既有的中文草稿「改得不像 AI 寫的」、「去除 AI 味」、「潤稿」。
- 幫小孩或學生寫作文 / 讀書心得（需要刻意降低 AI 痕跡）。
- 把 ChatGPT / Claude / Gemini 產出的中文稿改成自然口吻。

如果使用者要的是英文文章、程式碼、純翻譯（直譯逐字）、或者明確說「就是要 AI 風格的高大上版本」，不要套用這個 skill。

## 核心原則 Core Principle

1. **每一句話都要帶來新增的資訊**。如果一句話只是用不同詞彙重複前一句，刪掉。
2. **AI 的「華麗」幾乎都是空的**。看起來像金句、其實沒有資訊量的句子要砍。
3. **想砍字數不要一次砍太多**。從 1000 字直接砍到 300 字，AI 會把手腳都砍掉，結構會崩；應該分兩階段（1000 → 700 → 目標字數）。
4. **設定明確的讀者年齡層**。寫小孩作文時刻意把年齡層再調低一級（高中生作文就跟 AI 說「國二學生」），出來才會自然。
5. **批判性的合作**。AI 是助手不是權威，遇到它寫得怪、寫得空、寫得假，要當場指出並要求重寫，而不是接受。

## 八個必避的 AI 句法地雷

每個地雷都附「AI 慣用反例」與「自然改法」。寫完／改完一定要把整篇文章用這 8 條對照一遍。

### 地雷 1：「不是 X，而是 Y」句型氾濫

AI 極度喜歡先否定再肯定，連結論段也能連寫三個「不是…而是…」。

- ❌ 「木耳對他而言，從來不只是產品，而是他與媽媽之間最深的情感連結。」
- ❌ 「真正的財富，不是你口袋裡的數字，而是你對世界的認知。」
- ❌ 「不是你沒在努力，而是你還沒找對方法。」
- ✅ 「真正的財富是你對世界的認知。」（直接講肯定就好）
- ✅ 「他想做的，是替媽媽留下那碗木耳的味道。」（換個角度，不用否定句）

**重要陷阱**：請 AI「把『不是…而是』改掉」時，它常常只是換成「不只是…而是」、「並非…而是」這種同義變體。檢查時兩者都要抓。

### 地雷 2：囉嗦、換句話說、同義反覆

AI 怕讀者不懂，會用 6–8 句講同一個概念。每句單獨看都「對」，疊在一起完全沒新資訊。

- ❌ 「這筆錢沒有在流動，也就是說它沒有發揮價值。更具體地說，資產正在縮水。換言之，購買力正在下降。」
- ✅ 「這筆錢沒在動，購買力一直在掉。」

**檢查法**：每段唸完問自己「這段比上一段多講了什麼？」答不出來就刪一半。

### 地雷 3：強行解釋人物情緒

AI 不是人，沒有情緒，所以它會「硬塞」一個情緒解讀，而且解讀通常套路化（看著舊屋 → 終於明白什麼是家）。

- ❌ 「他看著空蕩蕩的舊屋，那一刻，他終於明白了什麼才是真正的家。」
- ❌ 「望著母親老去的背影，這讓人不禁感到一陣心酸。」
- ✅ 「他在舊屋站了很久，沒講話。」（讓畫面自己說話）
- ✅ 「媽媽的背影比去年又矮了一點。」（用具體觀察取代情緒結論）

### 地雷 4：強行升華（小事拉大道理）

AI 會把一件小事啪一聲擴張成「全宇宙級」的哲學命題。

- ❌ 「孩子拒絕了那塊棉花糖，這其實是一場關於人性慾望與自我克制的深刻對話。」
- ❌ 「她選擇走樓梯，這揭示了一種對現代生活的無聲抵抗。」
- ✅ 「孩子說他想等爸爸回來再吃。」（事就只是事，不要硬接道理）

**判準**：如果你的句子裡出現「這其實是一場…」「這揭示了…」「這背後是…」這類框架詞，先假設它是地雷，重新想一次有沒有必要升華。

### 地雷 5：強行製造戲劇感

AI 喜歡在段落末加一個誇張轉折，把「然後」寫成「然而真正的考驗才正要開始」。

- ❌ 「他終於存下第一桶金，然而真正的問題才正要開始。」
- ❌ 「一切看似順利，但命運的齒輪已悄悄轉動。」
- ✅ 「存到第一桶金的第二週，他被裁員了。」（用事實製造張力，不用旁白）

### 地雷 6：「有人說」式的假設

AI 沒做過田野，但又需要一個論點起手，於是常用「有人說 / 很多人認為 / 大家都覺得」當稻草人。

- ❌ 「有人說買房自住不划算，但其實……」
- ❌ 「很多人覺得 AI 會取代人類，事實上……」
- ✅ 「主計處 2024 年的調查顯示，自住買房的人佔……」（有來源就標來源）
- ✅ 直接寫自己的觀點：「我不認為買房自住不划算，原因有三……」

**例外**：如果真有來源，請 AI 把「有人說」換成具體出處；查不到出處就刪掉那個假設。Gemini 比較會老實回「無可考」，可以拿來查證引言出處。

### 地雷 7：直白情緒詞 ＋ 翻譯腔代名詞

AI 訓練資料大量是英文翻譯，會帶兩個壞習慣：
（a）情緒寫得太直接，不會用形象代替；
（b）句首動不動就加「這」「那」當主詞。

- ❌ 「我突然覺得非常孤獨，像是整個世界都拋棄了我。」（孤獨 = 被拋棄是套式同義反覆）
- ❌ 「望著母親老去的背影，這讓人不禁感到心酸。」（「這」是英譯腔）
- ✅ 「望著媽媽老去的背影，我突然有一點心酸。」（去掉「這」、去掉「不禁」）
- ✅ 用具體形象：「問君能有幾多愁？恰似一江春水向東流。」（成熟作家不直接點名情緒）

### 地雷 8：空洞的「高大上」包裝

AI 為了顯得有學問，會把日常事情包成名詞片語（結構性、機制性、系統性、深層的、本質上的……）。問它「這個 XX 性跟前文有什麼關係」，它常常會自己承認沒關係。

- ❌ 「他不愛社交，這揭示了一種結構性的疏離。」
- ❌ 「這背後反映的是一種本質性的時代焦慮。」
- ✅ 「他不愛社交，週末多半一個人在家。」

**自測法**：把「結構性的 / 本質性的 / 深層的 / 系統性的 / 機制性的」這類修飾全部拿掉，句意如果沒變淡，那它本來就是裝飾品，刪掉。

## 寫作流程 Procedure

開始寫之前，先把下面這份進度清單複製到你的回應裡，一邊做一邊勾選：

```
寫作進度：
- [ ] 1. 已問清主題 / 讀者 / 字數 / 既有草稿四件事
- [ ] 2. 已用「降一級」的讀者年齡層設定
- [ ] 3. 初稿產出（字數寫寬鬆，比目標多 30％以上）
- [ ] 4. 用八地雷正規表達式掃一遍、改掉命中項
- [ ] 5. 分階段砍到目標字數（1000 → 700 → 目標，不一次砍太多）
- [ ] 6. 把每段最後一句單獨抽出來排在一起看，確認不是心靈雞湯短句集（金句陷阱）
```

### 1. 接到任務先問清四件事

如果使用者沒給齊，先補上再開始寫：

1. **主題與重點訊息**（一句話講完想傳達什麼）。
2. **目標讀者**：年齡層 / 身份 / 平台（FB 貼文 vs 書稿口吻差很多）。
3. **目標字數**。
4. **既有草稿**（若有，貼進來；若是要從零寫，跳過）。

### 2. 設定讀者年齡層的小技巧

要寫得自然，**把指令裡的年齡層往下調一級**：

| 實際讀者 | 寫給 AI 的設定 |
| --- | --- |
| 高中生作文 | 「這是一個國中二年級學生要寫的報告」 |
| 國中讀書心得 | 「這是一個小學六年級學生的報告」 |
| 一般 FB 貼文 | 「寫給一般上班族，不要文謅謅」 |
| 商業文案 | 指定客群（年齡、職業、消費場景），不要寫「現代人」 |

### 3. 字數策略：先寬鬆、再精煉

目標 N 字，**不要一次叫 AI 寫 N 字**。

- 目標 400 字 → 先寫 700–800 字 → 自己挑能留的句子 → 改到 400 字。
- 目標 1000 字 → 不要直接砍到 300，先砍到 600–700，再砍。
- 直接從 1000 砍到 300，AI 會把過渡句、邏輯接點都砍掉，整篇變散。

### 4. 保留句子的指令寫法

請 AI 改稿時，要明確指出**哪幾句不准動**，否則它常常把你最喜歡的那句改掉重寫：

> 「請改寫以下段落，但第二句『___』和第四句『___』請完全保留，不要動字。其他段落可以重寫得更精煉。」

### 5. 寫完後的自我檢查清單

逐項用文字搜尋掃一遍。出現一次不一定是地雷，**出現兩次以上幾乎一定是**：

- [ ] `不是.*而是` / `不只是.*而是` / `並非.*而是`
- [ ] `從來不只是` / `從來不是`
- [ ] `這其實是一場` / `這揭示了` / `這意味著` / `這背後是`
- [ ] `結構性的` / `本質性的` / `深層的` / `系統性的`
- [ ] `讓人不禁` / `讓人感到` / `不禁讓人`
- [ ] `然而真正的` / `但真正的.*才正要` / `命運的齒輪`
- [ ] `有人說` / `很多人覺得` / `大家都認為`（沒附來源就刪）
- [ ] 句首贅字「這」「那」當主詞（英譯腔）
- [ ] 「換言之」「也就是說」「更具體地說」連續出現（同義反覆）
- [ ] 每段是否多講了上一段沒講的事？答不出來就合併或刪除。

可以用搜尋工具一次掃完：

```regex
不是.{0,15}而是|不只是.{0,15}而是|並非.{0,15}而是|從來不只是|這其實是一場|這揭示了|結構性的|本質性的|讓人不禁|讓人感到|然而真正的|有人說|很多人覺得|換言之|也就是說|更具體地說
```

### 6. 結尾不要硬下金句

AI 特別愛在每段最後丟一個總結金句，或結尾來一段「升華」。**寫完整篇後，把每段最後一句單獨抽出來看**，如果這些句子串在一起像一篇「心靈雞湯短句集」，就代表你掉進金句陷阱了，回去拆掉。

逐字稿原話：「每一句話都要由新增資訊結束，後面兩句也不要了。」

## 邊界 What This Skill Does NOT Do

- 不負責查證引用的事實準確性（人名、年份、論文出處需要另外查；Gemini 比較會老實回「無可考」）。
- 不處理翻譯任務（中譯英、英譯中請另外指定）。
- 不替使用者決定立場或觀點：地雷 6 要求作者自己給出論點，skill 不會替使用者編造立場。
- 不適用於詩、歌詞、文言文這類本來就講究修辭密度的文體 —— 八個地雷主要針對散文、文案、貼文。
